# Changelog

## v0.1.2 — 2026-11-11

- Clarify target speed versus clip timing, per-model viewing elevation, and node rotation versus rotation bindings.
- Label framework-only toolbox actions and separate mod metadata from building definitions in the authoring guide.
- Include the starter material's MIT license in generated mods, with bilingual reuse instructions.
- Document how authors can hide the generic animation panel and correct listing wording.

明确目标转速与动作时间的区别、模型俯角和两种旋转字段；标明工具箱操作范围，补齐新建MOD的许可文件及说明，并补充隐藏通用动画面板的方法。

## v0.1.1 — 2026-11-11

- Keep Workshop listing drafts and prepared release archives local; the repository provides sources, tools, guides and reusable examples.
- Update manual installation instructions and exclude publisher files from developer packages.
- Add a field-by-field authoring guide for complex mechanisms, including author responsibilities and a joint-by-joint verification sequence.
- Runtime rendering and animation behavior are unchanged.

工坊发布文案与成品压缩包改为本地交付；更新安装说明及打包范围，绘制和动画行为保持不变。

## v0.1.0 — 2026-11-11

Initial stable release.

- Hierarchical rigid-part models with continuous turning, independent elevation, recoil, lifting and folding.
- Flat shading, outlines and separate rendering backends for RimWorld 1.6 and 1.7.
- Animation parameters, clips, anchors and saved playback state.
- Three optional animation examples, editable models and a shield-generator modeling case.
- Authoring compiler, rigid GLB importer, mod template and local build/test tools.
- English and Simplified Chinese controls, documentation and Workshop descriptions.
- Animation controls fit the screen when interface scaling is increased.

初次正式发布。提供机械动画与绘制框架、三个可选示例、建模案例、中英文教程及本地制作工具。
