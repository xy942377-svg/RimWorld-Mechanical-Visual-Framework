# RimWorld Mechanical Visual Framework
# 环世界机械动态视觉框架

[English](README.en.md) · [上手教程](docs/quickstart.md) · [模型与动画格式](docs/model-format.md) · [接入接口](docs/api.md) · [开发交接](docs/handoff.md)

将分部件的三维机械模型投影到 RimWorld 地图：连续转向、独立俯仰、后坐、升降、折叠，以及多个动作同时播放。**0.1.0-candidate1 是首个可运行候选版，支持 RimWorld 1.6 / 1.7。** 作者：Grey·Oviin/OpenAI Assisted。

每个部件有自己的局部坐标和转轴，父部件运动会传给子部件。游戏中按姿态更新投影网格、平面明暗和粗描边；不需要为每一度预绘一张图片，也不需要在游戏里启动 Blender 或三维摄像机。这里的“二维视觉”指最终贴合地图的显示方式，不是 PNG 序列播放器。

## 两个入口

- **Steam 创意工坊**：面向玩家的框架运行包。当前已准备上传包，尚未公开发布创意工坊条目。
- **本 GitHub 仓库**：源码、原创示例、制作工具、教程与版本包。无需另外访问教学网站。

GitHub 仓库下载的项目目录中，`Mod` 是框架 MOD，`Examples/Mechanisms` 是可选示例 MOD。不要把整个仓库当成一个游戏 MOD 安装。

直接下载：[框架运行包](Downloads/RMVF-0.1.0-candidate1-Workshop.zip) · [可选示例包](Downloads/RMVF-0.1.0-candidate1-Examples.zip)。
完整开发材料使用仓库的 Code → Download ZIP，或克隆本仓库。

## 先体验，再制作

1. 将 `Mod` 和 `Examples/Mechanisms` 分别复制到 RimWorld 的 Mods 目录，换成便于识别的文件夹名。
2. 游戏中按 **Core → Mechanical Visual Framework → RMVF Mechanical examples** 启用。
3. 在“杂项”建造菜单找到三个示例；选中建筑，打开“动画控制”。
4. 观察转臂、升降折叠机构和三联装炮塔。炮塔例子展示旋转、独立俯仰和后坐；本例不包含战斗逻辑。
5. 制作自己的 MOD：下载开发工具包，双击 `Start.cmd`，先配置已有 Python 路径，再选择 **New mod**。新建的最小示例不需要编写或编译 C#。

已有预编译的 1.6 / 1.7 DLL。纯模型作者需要 Python 3.10+；仅修改框架或编写游戏逻辑适配器时才需要 Roslyn C# 编译器及对应版本游戏程序集。工具不会自动安装软件。首版工具箱菜单使用英文，游戏内界面提供原生英文和简体中文。

## 边界

首版支持**刚性部件机构**。不包含骨骼蒙皮、柔性变形、IK、自动碰撞、导航、载具载人、伤害或射击系统。炮口挂接点提供视觉坐标，不会自动决定游戏弹道。GLB 导入也不是通用材质/动画转换器，支持范围见教程。

旋转速度、动作播放和绘制互相分开。新增武器、发电机或载具时，游戏逻辑只需给视觉参数下达目标值，不能把伤害计算写进绘制函数。
