# Current status

[中文](status.md) · [English home](../README.en.md) · [Verification](verification.en.md) · [Releases](release.en.md)

Framework: 0.1.0-candidate1. Documentation revision: docs3. Date: 2026-11-10. This is a development candidate.

The project includes runtime files and matching sources for 1.6 and 1.7, three in-game animation examples, editable models, a JSON compiler, a GLB importer, mod templates, a toolbox, tutorials and a shield-generator modeling case. This revision completes the eight detailed English guides and revises instructions, interface text and error messages. Framework animation, rendering, saving and gameplay behavior are unchanged.

In-game checks cover RimWorld 1.6.4871 and 1.7.5000. See [verification](verification.en.md) for the tested scope and documentation checks.

The [GitHub repository](https://github.com/xy942377-svg/RimWorld-Mechanical-Visual-Framework) provides source and downloads. The Steam Workshop listing has not yet been published. See [releases and downloads](release.en.md) for download locations and packaging.

Further work includes testing more models, measuring performance with multiple visible instances and connecting specific mods' gameplay logic.
