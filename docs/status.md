# 当前版本

框架：0.1.0-candidate1。资料修订：docs2。日期：2026-11-10。当前为开发候选版。

项目包含1.6和1.7运行文件及对应源码、三个游戏动画示例、可编辑模型、JSON编译器、GLB导入器、MOD模板、工具箱和教程。本次修订更新文字，并加入护盾发生器的建模案例；框架动画、绘制、存档和游戏逻辑保持不变。

运行示例的实机检查覆盖RimWorld 1.6.4871和1.7.5000。详细测试项目及资料修订的检查结果见[验证记录](verification.md)。

[GitHub仓库](https://github.com/xy942377-svg/RimWorld-Mechanical-Visual-Framework)提供源码与下载。创意工坊条目尚未发布。下载入口和打包方法见[发布与下载](release.md)。

后续工作包括更多模型的使用测试、同屏多实例性能测量，以及具体MOD的游戏逻辑接入。
