# 本地验证范围

[English](verification.en.md) · [中文首页](../README.md) · [维护指南](handoff.md)

版本：**v0.1.2**。验证日期：2026-11-11。环境：Windows，RimWorld 1.6.4871和1.7.5000；启用Core、框架、机械示例和本地测试组件。

## 已验证的功能

- 部件转轴、父子旋转、炮管俯仰和旋转后的局部后坐。
- 连续转向、359°至1°的最短转向、多个独立动作、循环、暂停和停止。
- 不同实例的状态互不影响。挂接点查询后仍能正确更新网格；静止时更新0个节点，单炮后坐更新1个节点，整体转向更新4个活动节点。
- 参数当前值、目标值、动作时间和暂停状态的保存与恢复；建筑移出地图后重新生成时恢复姿态。
- 三个示例同时绘制，并由正常游戏更新驱动动画。两版模型画面和控制面板均已检查；窗口按界面缩放后的可用空间调整大小。
- 十一项工具测试，覆盖模板生成、重复构建、输入检查、GLB坐标与层级转换，以及正式打包前的验证记录检查、文件变动检查和已有包的保留。

源码与两版DLL通过构建清单对应；三个示例的几何、贴图和源文件通过哈希与重建结果核验。发布包检查包括文件清单、压缩完整性和包内文件哈希。

## 如何复现

按[维护指南](handoff.md#构建与测试)运行工具检查与两版自动游戏测试。测试工具随源码提供，运行过程和结果保存在本地。正式打包步骤见[版本与发布](release.md)。

护盾建模案例包含独立构建器、同一角部模型的四次旋转放置，以及基座和球体的独立导出。它用于学习建模与投影，没有作为第四个游戏建筑安装；用法见[案例说明](../Modeling/ShieldGenerator/README.md)。

本版本的检查未覆盖完整存档的跨版本迁移、不同硬件的性能基准和复杂MOD组合。GLB导入测试使用合成模型；实际输入应符合[导入条件](quickstart.md#4-从建模软件接入)。
